# AI Games

Three short browser games about how AI works, for first-year engineering students.
Made by Dr. Ansith S, FACTS-H Lab, IIIT Kottayam.

| Game | What students learn |
| --- | --- |
| [Guess the Next Word](next-word.html) | A chatbot writes by predicting the next token, and the words before it change the prediction. |
| [Hallucination Hunter](hallucination-hunter.html) | AI can give a wrong answer that sounds correct, so important facts need checking. |
| [Fix the Model](fix-the-model.html) | AI learns whatever pattern is in its examples, so poor examples give a poor model. |

Each game is one HTML file. It needs no installation and no login, and it runs in any phone browser.

## Change a game

Each game has a block marked "Edit these" near the top of its script. Change the sentences, questions or mangoes there.
