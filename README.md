# AI Games

Three short browser games about how AI works, made for the inauguration of the CSE–AI Association at Thejus Engineering College (5 November 2026).

| Game | What students learn |
| --- | --- |
| [Guess the Next Word](next-word/) | A chatbot writes by predicting the next token, and context changes the prediction. |
| [Hallucination Hunter](hallucination-hunter/) | AI can state false things confidently; always verify. |
| [Fix the Model](fix-the-model/) | A model learns whatever pattern is in its data, so biased data gives a biased model. |

Each game is one self-contained `index.html` file: no installs, no login, no tracking. It runs on any phone browser.

## Run it

Open the live site, or download a folder and open `index.html` in a browser.

## Change it

Every game has an "Edit these" block near the top of its script. Change the sentences, claims or mangoes there; nothing else needs editing.

**30-day challenge idea:** fork this repository, improve one game or add a fourth, and show it at the association's first event.
